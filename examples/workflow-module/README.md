# 独立工作流模块示例

这是独立的 React 应用，通过 Kaus 模块 SDK 调用通用工作流、任务与配置界面。Kaus 不预装它。

```sh
npm install
npm run check
```

在 Kaus 的工作台选择“添加模块”，选择构建生成的 `dist` 目录。首次配置 Project、已接入的 Agent、模型和使用权限。示例步骤仅存在于本模块；首次保存或运行时才写入模块工作流。任务在 Kaus 后台持续，离开页面后重新进入会恢复运行状态；需要审批时打开对应对话。

用 `npm run dev` 可独立预览编辑器。预览可以编辑和排序示例步骤；任务执行需从 Kaus 加载模块。模块不接触 Kaus 登录凭据或 Agent 密钥。
