这个 demo 不是重做聊天框，而是在 xterm 视觉层旁边挂一个原生 textarea 输入桥。

外挂语音输入、系统听写、中文 IME、整段粘贴先进入 textarea，再被转发到模拟 PTY。

  • 1. 点击右侧终端区域，让输入桥获得焦点。
  • 2. 用微信语音转文字/系统听写输入一段话。
  • 3. 按 Enter 发送；Shift+Enter 换行。
  • 4. 点「显示捕获层」可看到真实 textarea。
