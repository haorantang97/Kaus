# Agent icon sources

Icons identify their respective engines; trademarks belong to their owners. No affiliation or endorsement is implied. Assets are served locally, without third-party tracking.

- Hermes Agent, Claude Code, Codex, OpenCode, Gemini, Antigravity, Qwen, OpenClaw, Kilo Code, Goose, Cursor, GitHub Copilot, Devin, Grok, Command Code, Z.ai (ZCode) and DeepSeek: [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/329f378cbd1a88f45b60cd096b9111ce16f3ea39/packages/static-svg/icons), MIT; see LICENSE-lobe-icons. Both DeepSeek adapters share the provider mark; both Hermes adapters share the engine mark.
- Oh My Pi: [official icon](https://github.com/can1357/oh-my-pi/blob/7695ddb7dd25fce453444427b1edd49d12f86ead/assets/icon.svg), MIT; see LICENSE-omp.
- Pi coding agent: SVG transcription of the [official terminal pixel logo](https://github.com/badlogic/pi-mono/blob/2b0a123de98318c2ff8069661721ce0c3794c34e/packages/coding-agent/src/modes/interactive/components/pi-logo.ts), MIT; see LICENSE-pi. Pixel positions and original colors are preserved. This is unrelated to Inflection Pi.

Color variants from the same pinned Lobe Icons revision are used for Claude Code, Codex, Gemini, Antigravity, Qwen, OpenClaw, GitHub Copilot, Devin and DeepSeek. Pi and Oh My Pi retain the colors embedded in their original assets.

OpenCode uses a black tile with a white mark; Hermes uses a white tile with a black mark. Other marks without a bundled color variant follow the interface's neutral foreground and surface colors. Kilo uses its upstream avatar palette (#F8F676 / #1A1A18), recorded in the same revision's `src/KiloCode/style.ts`. Monochrome marks retain their original geometry through a CSS mask.

## Deliberately unbundled

- Crush: current [upstream license](https://github.com/charmbracelet/crush/blob/7c09acfffb046ab9594fd8233a44c26470e7f9e8/LICENSE.md) is FSL-1.1-MIT. Its current artwork is not bundled pending clarification of redistribution terms for Kaus.
- Alma: [official site](https://alma.now/) provides artwork, but no explicit artwork redistribution license was found.

These engines, and unknown/custom engines, use the existing Lucide Bot icon on a neutral tile. No letter placeholders or invented brand marks are used.
