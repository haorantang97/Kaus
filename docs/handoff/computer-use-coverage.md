# 电脑操作覆盖 · 2026-10-23

**已建立共用接入；尚不能宣称所有 Agent、账号和模型都通过真实电脑操作验收。** 原生 Agent 的桌面 App 能操作电脑，不代表它的 CLI/ACP 自动暴露相同工具。

## 自动选择的准确含义

用户在设置中启用后，Kaus 在会话运行准备时分别解析 browser 与 desktop：

1. 当前连接已暴露的原生能力。
2. 当前 Project 已选择的 MCP 工具。
3. 桌面缺口使用 CuaDriver；纯浏览器缺口使用 Playwright MCP。

切换设置会在空闲运行的下一轮重新投影，保留原生会话。自动选择不是运行到一半失败后重放任务，也不是两套等价桌面工具同时交给模型。明确禁用/拒绝会终止选择；已暴露但待设置的原生工具先完成自己的设置。模型是否理解图像、是否会正确使用工具，仍由该模型和原生 Agent 决定。

## 授权与共享电脑

- 默认关闭，由用户启用。首次启用安装/复用已核验签名的 CuaDriver；当前锁定版本为 0.37.0。macOS 辅助功能和录屏授权必须由用户完成，设置按钮可直接跳转及定位实际应用。
- CuaDriver 的桌面投影限定已验证工具表，观察图像保留在工具记录内；不额外开放任意脚本或授权设置工具。
- Project 的关闭/拒绝、模块 `context-only` 和原生审批仍生效。原生无法逐会话撤权的连接标为由 Agent 管理；关闭 Kaus 投影不能被描述为撤销了其全部原生权限。
- 同一桌面只能有一个 Kaus 所有者；组成员/多组排队，取消和恢复需确认旧任务结束。浏览器共享目标也参与控制，明确隔离的浏览器上下文可以并行。
- 当前锁跨完整 Agent 回合；暴露桌面能力的纯文字回合也可能等待。它是协作调度机制，不是 OS 沙箱；Kaus 之外启动的程序不受它控制。
- 终端接管只对已验证能携带相关工具的入口生效；卡片 MCP 接入不自动代表原生 CLI 具备同等电脑操作能力。

详细原生差异、资源回收和版本条件见 [技术说明](../computer-use.md)。新设备先完成授权，再执行临时窗口验收，不复制本机“已授权”的结论。
