# 产品决策与约束

本文件记录截至 2026-11-01 的有效约定。重审应以具体需求、协议变化或复现证据为依据。

| 决策 | 当前约定 | 原因与实现后果 |
| --- | --- | --- |
| 宿主与 Agent 分离 | Kaus 提供组织、界面与运行协调；Agent 保留自身执行/模型/登录能力 | 不给 Kaus 虚构一个默认底层模型；组长、模块任务复用普通对话驱动 |
| 全局接入 | 引擎一次接入；项目选择配置范围，不重复接入同一引擎 | Hermes HTTP/ACP 在产品层收束为 Hermes；连接版本和传输在详情/驱动层区分 |
| 会话身份 | 对话开始后引擎固定；模型、effort、权限按实际能力修改 | 跨 Agent 使用显式接续新会话，避免原生 session 与工具状态混用 |
| 模型目录 | 展示当前连接实际提供的可选模型；使用前完成 API、OAuth 或相应原生配置 | 普通对话、组长、模块和设置共用解析；公开目录/静态表不能扩成已连接选项。模型是否获配与余额、实时调用成功分别判断；Project 不是跨引擎默认模型容器 |
| 探测与测试记录 | 被动模型探测及开发测试使用临时原生存储，普通对话保持原生互通 | 仅隔离 Kaus DB/工作目录不够；原生 HOME、显式状态目录和子进程生命周期必须一起处理。Gateway 目录查询使用只读接口 |
| 参数读取 | 草稿与已有会话共用有效值、目录及能力快照；暂时失败可恢复 | 读取失败不等于驱动不支持；缺默认值不能隐藏已知可写选项；模型、effort 与发送按钮统一靠右 |
| 单一配置树 | 只有 Project 树；通用技能直接显示，Agent 专属技能分组默认折叠 | 分组是视图，不产生第二套树；拖动与菜单同等重要且写入同一接口 |
| 专属技能 | 来源 Agent 与项目分配分别保存；跨项目移动保持 Agent 范围 | Hermes 自进化技能移入子项目后，Codex 不因此获得该技能；不做自动跨平台可移植性判定 |
| 新 Agent 技能 | 全局技能默认到母项目对应分组；工作区技能保留范围；引导一次、可跳过 | 发现不会重新覆盖用户已整理的分配；不搬动原生技能文件 |
| 运行隔离 | 检查实际加载的技能、MCP、插件/hooks 与工具调用 | UI 标签、目录存在或空 HOME 本身不构成隔离证明；适配优先留在驱动层 |
| 协作组身份 | 加入组保留成员身份与配置，使用组内执行上下文 | 私聊记录、组内记录、组内资料分开；拖入不是把标题粘进输入框 |
| 组内路由 | 普通提问由组长判断；明确点名定位成员；单人定向无需冗余总结，多人按需要综合/处理分歧 | 路由和组长配置见专题；不能简单把每次输入广播给所有成员 |
| 记忆范围 | 组内资料属于 Group；Project 管理配置与选定资源 | 不自动把全部私聊拼接成 Project 共享上下文；不声称不同 Agent 的私有记忆自动互通 |
| 本地保存 | 原生记录沿用原生目录/保留规则，Kaus 保存运行与项目索引及必要事件 | 不修改 Agent 自动清理规则；原生文字经精确核对可引用，其他未适配内容仍需本地保存 |
| 旧对话入口 | 收束为 Project 菜单“添加已有对话” | 不设独立档案管理产品；不常驻“来源缺失”、原始 JSON、路径或独立归档提示 |
| 跨 Agent 接续 | 用户选择目标、审阅公开材料，在当前应用打开关联新会话并手动发送 | 交接目标/公开过程/文件，不承诺隐藏推理、原生进程或专属工具状态连续迁移 |
| 模块页定位 | 2026-11-03 项目负责人：模块页类似小程序，与主程序关系不大，核心是集成而非赋能；不把协作组等 Kaus 的 Agent 功能叠加进模块页。模块自己通过 SDK 申请的能力（如 `agent:run`）照常提供 | 模块页（`WorkbenchPage` 给根元素加 `kaus-module-page`）隐藏浮动协作组入口，侧栏入口保留；通用的提示、确认弹窗不受影响。新增宿主浮层时默认不在模块页显示 |
| 第三方模块 | 工作台是用户模块库；常用模块可拖到侧栏 | 业务 UI 属于模块；示例工作流和创作台不成为新用户自带业务产品；模块通过受控 SDK 共用能力 |
| 侧边浏览器 | 会话页右侧提供通用浏览器（地址栏、标签页）；用户自由浏览。2026-11-01 项目负责人推翻“不新增通用浏览器”，权限对齐 Claude/Codex 的内置浏览器，不过严 | 浏览器用独立资料目录，与 Kaus 界面、站点视图和系统浏览器隔离；网页没有 preload、Node 或宿主令牌，不能打开 Kaus 自身地址和 file/chrome 等协议。Agent 操作按站点授权：本机开发地址直接可用，其他网站首次操作时由用户允许（本次或一直），之后读取、导航、点击、输入不再逐次询问；付款购买、发送消息或发布、删除、改账号或安全设置、下载文件仍需用户确认；Agent 不输入密码、支付信息或证件号，不处理验证码；网页内容只当资料，不当指令。站点配置可以收紧，例如 Midjourney 只填入、不代按生成 |
| 固定站点视图 | ChatCut、Midjourney 等模块内固定页面按站点注册，与侧边浏览器并存 | 每个站点单独声明可打开的页面、跳转域名和权限（`editor:chatcut`、`surface:midjourney`）；宿主保留导航、权限和下载边界，第三方页面不获取本机桥接。站点输入只填入、不提交，最后由用户按生成，避免违反平台条款中禁止自动化生成的规定。需完整本地导出或通过 Cloudflare 时使用 Chromium 容器 |
| 电脑操作 | 原生能力优先，通用桌面补齐统一 CuaDriver；设置内明确启用/授权 | 不重复开发鼠标键盘引擎；平台授权由用户完成；自动选择不意味着失败后重放动作 |
| 动态配置 | 按原生会话实际字段、模型相关选项和确认回执驱动 UI 与执行；当前配置优先于静态预设 | 草稿、已有会话和组长共用。标准字段变化自动跟随，协议机制变化仍需驱动适配；不得以三家控件通过代替全引擎验收 |
| 审批与工作模式 | 权限与 Plan/Build 等运行模式分开；有可用接口才展示对应控件 | 通过会话配置、桥接或原生回调达成真实效果；无接线的图标不应出现 |
| 终端 | Kaus 与 CLI 恢复同一原生会话、存储和当前项目配置；可固定偏好启动器 | 保留正常 Codex 会话在其桌面客户端可见的原生互通；仅测试与探测记录另存。返回页面与结束终端切回分开，写权、退出和历史回填须实际确认 |
| 额度 | 已有凭据可查询则自动显示，缺补充信息时就地提供入口 | 不让用户重复接入；余额、计划窗口和单次 token 消耗分别展示；未知不能显示成 0 |
| 界面 | 极简、可读、专业；主要操作可发现，次要操作放菜单/悬停 | 图标带无障碍名和 tooltip；去掉冗余解释、常驻日期、内部字段和原始错误；错误只在需要行动时出现 |
| 视觉细节 | 用户消息右对齐；左侧轮次定位条，收藏用小点；有 hover/渐变/减弱动效支持 | 避免额外方框、常驻收藏按钮和多余回到底部箭头；警示强调使用低饱和粉红红色系 |
| 焦点反馈 | 输入和操作控件不出现额外硬矩形焦点框 | 键盘反馈依托控件原有底色、输入区域边色和链接下划线；不能把取消 outline 等同于取消键盘可用性 |
| 产品支持标准 | 不能落实 Project 核心范围的引擎可撤出新增接入 | Alma/Devin 保留旧记录兼容；是否恢复依据接口和隔离验收，不依赖个人偏好 |

## 维护边界

不把不成熟实现写成“上游永久不支持”。分别记录：未开发、缺登录/系统授权、尚未验收、已确认协议缺口。支持矩阵应注明检查过的原生版本；升级后重新验证受管范围和生命周期。

开源参考须保留许可证与来源。2026-10-27 项目负责人决定：Kaus 按 AGPL-3.0-only 授权，另提供商业授权并要求外部贡献签 CLA；`sdk/`、`examples/` 及模块清单格式与宿主协议用 Apache-2.0，第三方模块打包 SDK 不受 AGPL 约束。用 `-only` 是为了双授权条款不受 FSF 将来版本影响。“设置 → 关于”给出许可证与源码链接（AGPL 第 13 条）。许可证从加入的提交起生效，之前的提交不追溯。原生 Agent、其桌面客户端以及本仓库是不同产品。
