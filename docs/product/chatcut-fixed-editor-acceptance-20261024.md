## 真实验收

独立工作台通过官方 OAuth 及短时编辑器入口登录，导入合成 A/B 视频，将两段各裁成 3 秒再连续拼接。浏览器本地导出完成并落盘。

Kaus 开发预览复用同一工作台已有授权，在独立 Chromium 会话打开同一项目，按官方提示重新关联仅在旧容器缓存的本地素材，直接在编辑器里点击导出。文件真实落盘，H.264、1280×720、30fps、180 帧、6 秒视频，AAC 48kHz 双声道；完整解码无错误。切出模块再返回保留时间线与导出结果；宿主设置弹窗显示时剪辑视图让出画面，关闭后恢复。

首次 iframe 方案登录受限，WKWebView 方案的官方导出明确返回 `browser_unsupported`。最终路径是独立 Chromium 45 固定视图，不伪造 User-Agent、关闭网络安全或自动改为云渲染。
