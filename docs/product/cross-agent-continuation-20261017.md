# 跨 Agent 接续

## 使用路径

对话菜单或历史详情中的“用其他 Agent 接续” → 选择目标 Agent → 审阅交接内容及附件 → “打开接续对话”。新对话在当前应用窗口打开，草稿由用户发送后开始执行。原对话保留原有 Agent、配置和记录。

新对话顶部提供原对话链接和具名的交接记录文件；文件点击后使用现有文件预览。原对话已被删除时仅保留标题，不产生失效跳转。

## 交接内容

- 自动提取最初请求、最新请求与近期公开交流，按原顺序排列。超长单条取首尾片段，整体不超过 48,000 字符。这里是可编辑的原文摘录，不调用额外模型，不把推断写成已确认的结论。
- 完整公开正文作为本次交接的参考文件。历史中的隐藏思考、失败投递、认证信息和原生会话状态不进入交接内容。
- 编辑区中的本地 Markdown 文件链接展示文件名；交接记录保存原文。用户在任务说明中直接输入的路径仍保持原样。
- 目标 Agent 可接收的附件由用户确认。未携带附件列在展开的配置详情中，常态界面不展示文件错误。

## 配置与发送

目标会话通过普通对话的 Project 能力解析路径启动。通用配置和目标 Agent 专属技能正常生效；来源 Agent 的专属项留在原配置中。审阅区展示生效项名称与来源专属项，隐藏运行配置和内部 ID。

交接记录的路径由服务端在首次发送时提供给目标 Agent，客户端草稿和公开消息只保存用户审阅的内容。引用仅允许当前新会话拥有的文件，客户端 metadata 不能授予文件访问权。它们是按需读取的背景资料；目标模型始终收到审阅过的有界正文。参考文件后续被主动删除时，不阻止正文发送。

完整交接记录内的文件链接仍保留原文。服务端为已确认携带的附件保存原引用到新会话副本的映射；点击原绝对路径、文件 URI 或明确且不重名的相对链接时读取副本。来源文件被删除后仍可打开已携带附件。未携带文件不会因此获得访问权限，也不通过文件名猜测其他路径。

原生记录可能包含实际发送的引用后缀。Kaus 使用发送时保存的完整文本哈希、可见正文哈希与长度，将精确匹配的记录还原为可见正文。此投射用于本地历史读取、原生文本映射及终端回填；不改写原生文件，不按模糊规则删除用户路径。

## 验收

- 临时 SQLite、合成历史和协议替身：源对话不变、并发创建幂等、重启草稿、配置变更拦截、附件读回、目标 Agent 实际收到其 Project 配置。
- 发送链：API → SessionHost → Driver 的实际入参包含参考文件；公开 user.message 不包含系统附加路径；后续消息不重复附加。
- 文件范围：其他会话文件、客户端伪造字段与 metadata 不会成为参考资料；附件能力检查保持原路径。
- 交接记录链接：普通对话与原生历史两种来源、原文件删除后的已选副本、未选文件拒绝、越界路径拒绝和原文不改写。
- 原生回读：精确哈希投射、内存与 SQLite 文本映射、原生来源不修改、终端历史回填、用户自写路径和编辑过的原生文本保持不变。
- 大文本：540,000 个汉字分片后可通过正常文件接口读取，首次上下文保持有界。
- 前端：审阅后才创建、失败保留输入、兼容附件选择、详情折叠、源链接、具名文件、焦点陷阱、嵌套弹窗和显式发送。

以上是合成数据和本地协议验证。各引擎的真实账号登录、模型回复质量及具体业务能力继续按对应引擎的实战验收记录评估。
