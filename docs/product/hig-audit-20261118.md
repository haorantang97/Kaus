# 按 Apple 人机界面指南（HIG）检查前端（2026-11-18）

负责人要求按 HIG 把 Kaus 前端仔细检查一遍。两路只读检查：交互模式；无障碍与视觉。HIG 页面没有在线抓取，「HIG 条目」是章节名加要点转述。对比度按 WCAG 公式算（浅色正文 `#242428` / 底 `#fcfcfb`，深色 `#edeadd` / `#16180f`）。路径相对 `web/src/`，行号以 ca03f0e 为准。

已当场修掉一条：技能树「移除本层分配」的撤销提示会用点击时最新的撤销令牌，期间若有别的改动会撤错；现在绑定这次移除自己的令牌，过期时后端回「此操作已无法撤销」（交互 #1）。

## 一、建议先做（影响大、规则明确）

| 组 | 内容 | 涉及条目 |
|---|---|---|

| B 菜单栏与快捷键 | 桌面版菜单只有 App / 编辑 / 窗口：补「文件」（新对话 ⌘N）、「显示」（侧栏、实际大小 / 放大 / 缩小）、「设置…」⌘,；现有 g+字母快捷键改为 ⌘ 组合并写进菜单 | 交互 5、6、36；视觉 7、8 |

## 二、其次

- 同一对象不一致：会话页 ⋯ 只有「接续 / 归档」，侧栏是「置顶 / 重命名 / 归档 / 删除」（交互 18）；7 套菜单实现收敛到 `RowMenu`，并补右键（交互 16、17）；菜单破坏性项放最后（交互 19）；术语「停用 / 屏蔽 / 禁止」「移除本层分配 / 删除本层赋值」统一（交互 20）；打开输入或对话框的菜单项加「…」（交互 21）。
- 模态：项目菜单里原地变表单（交互 14）；设置浮层上三层叠加（交互 26）；组内名称用模态（交互 27）；历史对话用 860 宽模态阅读（交互 28）；进行中无法退出（交互 48）。
- 写作：复制项目要用户填内部标识（交互 15）；提示里显示 `mcp/xxx-id`、`external-cli` 等内部值（交互 23、24）；错误对象被拼成字符串导致错误码丢失（交互 25）。
- 读屏与状态：侧栏行可交互元素嵌套（视觉 11）；当前项缺 `aria-current`（视觉 14）；工具失败只靠 6px 红点（视觉 15）；未读与待处理只靠颜色区分（视觉 16）；减弱动效后运行中完全没有标记（视觉 17）；确认框应为 `alertdialog`（视觉 40）。
- 深色模式：写死的颜色与悬停色（视觉 22–25）；没有「跟随系统」，窗口背景与 `nativeTheme` 不同步（视觉 26）；不支持增强对比度 / 降低透明度（视觉 27）。
- 点击区域：20–24px 的高频按钮扩到 ≥28px，⋯ 尺寸统一（视觉 33、34）；截断文字补 `title`（视觉 36、37）；最小窗口 1180×760 无法半屏（视觉 43）；按钮用手形光标（视觉 41）。
- 其他：侧栏没有搜索 / ⌘F（交互 37）；技能树搜索框无清除（交互 38）；部分图标按钮无 tooltip（交互 39）；同视图多个主按钮（交互 40）；编辑器 Esc 直接丢草稿（交互 41）；刷新与恢复共用逆时针图标（交互 34）；Pin 图标两种含义（交互 35）；Option 拖动复制时无「+」提示（交互 44）。

## 三、需负责人定

- 项目删除：删除后对话归档、项目可在「已归档」原位恢复，按 11-18 规则算可撤销；是改为撤销提示，还是记为不可撤销（交互 13）。
- 工作台模块移除：数据保留，能否改为撤销（交互 46）。
- 轮盘拖拽改上级后再弹确认，是否改为直接移动 + 撤销，并在菜单加「移到…」（交互 22；与待定的「改上级放在哪」相关）。
- 标题与当前项是否用 500–600 字重（视觉 30，涉及 11-03 字体决定）。
- 会话标题用等宽字体、行高 1（视觉 31）。

## 四、已符合、应保留

模态层（焦点圈在模态内、Esc 只关最上层、关闭后焦点回到触发元素、按下松开都在背景才关闭）；`RowMenu`（方向键、分隔线、右键定位、恢复焦点）；删除与撤销基本按 11-18 规则；多数确认按钮用具体动词并带危险样式；已知错误码本地化、细节收进「详情」；悬停才出现的控件多有 `:focus-within` 与触屏兜底；`prefers-reduced-motion` 覆盖较全；图标按钮几乎都有可读名称；toast 与错误有 live region；触屏下控件扩到 44px；`<html lang>` 随语言切换。

### 与我们的决定或风格有出入，需要讨论

| 条目 | Apple 建议 | 我们的规则 / 决定 | 开发方意见 |
|---|---|---|---|
| 菜单栏与快捷键（B） | 补「文件 / 显示 / 设置」菜单与 ⌘N、⌘,、缩放 | 一个功能一到两个入口；新对话已有侧栏、项目页两处 | 菜单栏和快捷键是系统层入口，建议不计入入口数；至少补缩放（现在完全无法放大文字） |
| g+字母快捷键 | 改为 ⌘ 组合并写进菜单 | 2026-11-23 定：去掉（product-decisions「快捷键」） | 已删除 |
| 对比度与字号（D） | 次要文字 ≥4.5:1，字号 ≥11px | 11-03「字体做轻」（字重与字号）；整体偏淡的风格 | 9.5–10px 的时间戳与计数提到 11px；灰字加深到达标会让界面变重，需你看效果再定 |
| 确认框加标题 | 标题说问题、正文说后果 | 文案简短、不过度解释 | 不加，保持一句 |
| 菜单项加「…」 | 需要进一步输入的菜单项加省略号 | 文案简短 | 可以不加 |
