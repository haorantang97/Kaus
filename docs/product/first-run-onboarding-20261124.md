# 新用户引导与「没有 Agent 时的入口」设计稿（2026-11-24，负责人已按建议定）

依据 `docs/handoff/product-decisions.md`「上线前工作（11-24）」③：先出设计稿。按「能抄就抄」，先看同类产品，再给 Kaus 的方案。未实现。

## 1 同类产品怎么做

| 产品 | 第一次打开到能发第一句话 | 没登录 / 没接入时 |
|---|---|---|
| Codex（ChatGPT 桌面 App） | 登录 ChatGPT → 选工作位置（对话 / 项目 / 文件夹）→ 选 Codex 模式 → 输入框，旁边有「Try an example」。设置里有「导入其他 Agent 的配置」（Claude Code、Cursor 的指令、技能、插件），26.608 起放进首次引导（第三方报道） | 未找到公开说明 |
| Claude 桌面版（Code 标签页） | 登录 → Code 标签页 → 选环境与「打开文件夹」→ 选模型 → 输入任务；文档给示例任务。权限模式在输入框旁，没有单独一屏 | 需付费方案时提示升级 |
| Conductor（最接近 Kaus：托管 Claude Code、Codex 等，用各自的登录） | 自动检查环境：GitHub 登录 + 至少一个 Agent；只需登录打算用的 Agent（`claude /login`、`codex login`），缺什么就引导补；然后添加仓库 → 自动建工作区 → 对话 | 2025-12 修过「没登录 Claude Code / Codex 的用户引导坏掉」的 bug——检测状态是容易出错的地方 |
| Goose 桌面版 | 欢迎页必须先选一种连接方式（API key / ChatGPT 订阅 / OpenRouter 等），OAuth 开浏览器再回来 | 设置里「重置提供方」回到同一欢迎页 |
| Zed | 第一次用 Agent 面板需先配模型或外部 Agent；没打开文件夹时显示欢迎页 | 一个开关可关掉所有 AI |
| Cursor | 登录 → 选文件夹 → ⌘I 打开 Agent，带建议问题；首次设置里可导入 VS Code 配置 | 未找到官方说明 |
| Warp | 不要求登录即可使用；输入框空时有建议问题 | — |

反复出现的做法：
1. **登录 → 文件夹 → 第一句话**是公认的最短路径；模型和权限不单独占一屏，放在输入框一行里并有默认值。
2. **托管型产品只检查、不代为登录**：检测本机已装、已登录的 Agent，缺的指向该 Agent 自己的登录命令；只要求「至少一个」。
3. **空状态是一屏选择**：列出几种接入方式，选一个就去做，做完回来；同一屏以后能再打开。
4. **用导入代替教程**：把用户已有的配置（Claude Code、Cursor 的指令与技能）带进来。
5. **引导不常驻**：没有清单式的「新手任务」；之后的帮助只是输入框里的示例问题。

## 2 Kaus 的情况

- Kaus 没有自己的账号，用户自己装、自己登录 Agent（与 Conductor 相同），所以第一步不是「登录 Kaus」，而是「至少接入一个 Agent」。
- 已有零件：接入面板会检测本机已装的 Agent（`probeState`、`detected`、`installed`）、能打开该 Agent 的登录终端（`loginAvailable`），接入时有「能力分配」邀请（导入已有技能 / MCP，`skillOnboarding`）。
- 缺口：一个 Agent 都没接时，新建对话页的 Agent 下拉是空的，没有任何入口。

## 3 方案

### 3.1 没有 Agent 时的入口（必须做，问题 1）

新建对话页在「一个 Agent 都没有」时，不显示空下拉，而是把输入框换成**一屏接入选择**（照 Goose / Conductor）：

```
            接入一个 Agent 开始
  ┌──────────────────────────────────────────┐
  │ [图标] Claude Code     已安装 · 未登录   [登录] │
  │ [图标] Codex           已安装 · 已登录   [接入] │
  │ [图标] Gemini CLI      未安装                   │
  │ …                                         │
  │                                其他 Agent… │
  └──────────────────────────────────────────┘
```

- 行内只有一个动作：已登录 → 接入；已装未登录 → 登录（打开该 Agent 自己的登录终端，回来自动刷新）；未装 → 行本身不可点，悬停显示安装命令。
- 「其他 Agent…」打开设置里现有的接入面板（全部预设与自定义）。
- 接入成功后直接回到正常输入框，选中刚接入的 Agent；接入时照常弹「能力分配」（即导入，照 Codex 的导入思路）。
- 标题一句，不加说明文字（AGENTS「不放解释性文字」）。

备选（更小）：保留下拉，在空下拉里只放一项「接入 Agent」，点了打开设置的接入面板。改动小，但用户第一屏看到的是一个空输入框，不知道下一步。

### 3.2 新用户引导（问题 3）

照「登录 → 文件夹 → 第一句话」，Kaus 对应为「接入 Agent → 工作目录 → 第一句话」，**不另做引导页**：

1. 第一次打开 = 3.1 那一屏（没有 Agent 时自然出现，接入后永不再出现）。
2. 接入后回到新建对话页：工作目录用输入框上现有的「选择工作目录」；不强制选，第一次发消息前没有目录时按现有规则提示。
3. 输入框为空时给 2–3 条示例问题（照 Claude / Codex / Cursor），点了填进输入框、不直接发送；发出第一条消息后不再显示。
4. 不做清单、不做逐步气泡讲解、不做欢迎视频（同类产品都不常驻）。

## 4 负责人决定（2026-11-24）

按开发方建议：3.1 用一屏接入选择；3.2 要示例问题（文案给负责人过目）；未安装只显示安装命令。原待定问题：

1. 3.1 用「一屏接入选择」还是备选「下拉里一项」。
2. 3.2 第 3 步的示例问题要不要（要的话由开发方拟 2–3 条，给你过目）。
3. 未安装的 Agent：只显示安装命令，还是提供「一键安装」（会在本机执行安装命令，需额外确认与权限设计）。建议先只显示命令。
