# 协作组资料契约

2026-09-24，用户授权实施。适用于现有右下角 Group。

## 归属与交互

Project 继续管理插件、Skills、指令和引擎配置继承。Group 资料只属于单个组，不沿 Project 树共享。同一原单聊可加入多个组，各组创建独立运行会话，保留 Binding、模型、厂家、effort、权限设置，原单聊保持独立。

在「资料」栏手动添加内容、导入 UTF-8 TXT/MD/CSV/JSON、粘贴有来源的单聊选段；组内消息可一键选入。保留来源和完整内容，可预览、编辑、删除。原有成员近况汇编折叠保留，不作为模型的共享背景。

最小化或关掉浮窗不会删除资料。关闭组保留资料供历史读取，禁止继续修改；成员会话继续服从既有保留/归档规则。旧 Project 记忆模型、仓库、能力类型与活动产品规范退出；有旧记录时只保存在无读写入口的退役表以避免数据丢失，空库直接删除旧表。

## 投递

每条用户发言固定一个资料快照，按该版本投给本次讨论的每位发言人，投递回执记录版本。每位成员以自身游标补齐组内已公开发言。新成员不依赖加入顺序判断资料容量。暂停/恢复不会隐式导入私聊历史。

资料修改要求当前讨论已停止。CAS 版本检查拒绝陈旧窗口的写入，保留用户草稿。删除条目从下一次讨论起撤回；旧轮次已经收到的资料仍属于历史，撤回不能抹除模型先前看到的信息。

当前上限为 20 条、标题与内容合计 12,000 个 Unicode 字符，超限拒绝，不静默截断。文本文件先导入编辑区，保存前再次计算；最多 48 KB。无自动摘要、语义判定、嵌入检索或额外基础模型调用。

## 严肃边界与后续验收

- 字符上限是本版产品边界，**不是模型 token 容量估算**。组内时间线与原生会话仍会增长；各厂家精确预算、留出输出空间、超窗前提示和保真压缩尚需单独开发。当前上游拒绝需明确报错，不能宣称任意长度都能运行。
- 独立 Native Session 隔离对话历史。Binding 的原生长期记忆文件、文件工作区和工具权限仍沿用引擎能力；共享同一 Binding 的引擎若自行写入长期记忆，可能跨会话生效。这需要 Driver 级记忆写入控制或独立运行目录，不能靠 UI 或一句提示承诺严格保密。
- 所有资料都是参考文本，不能提升权限；选入观点不代表已确认事实。没有自动真假、冲突或替代关系判定。
- 资料按需手工选入；不支持 PDF/二进制解析，不声称是完整知识库。文件权限及多用户身份鉴权沿用现有本机 Kaus 模型。
