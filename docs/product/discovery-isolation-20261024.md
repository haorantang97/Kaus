# 探测隔离与当前连接模型 · 2026-10-24

## 产品规则

- 模型菜单展示**当前连接实际提供的可选模型**。用户先完成原生 API、OAuth 或其他连接配置；Kaus 复用该连接，不要求重复接入。
- 测试与目录探测使用临时原生数据目录，结束后回收进程并删除临时状态。普通 Kaus 对话继续使用原生目录，保留与原生 CLI、桌面端的历史互通。
- 不以静态厂商全目录、未连接的公共模型清单或“待确认”分组填充菜单。原生未提供模型选择器时继续使用原生默认行为。
- 目录表示当前连接提供的选择，不额外对每个模型发送付费请求来验证额度或密钥有效期。实际生成被服务拒绝时按原生结果处理。

## 根因与实现

ACP 通常要先创建会话，才能返回模型和配置选项。关闭探测连接只结束进程，并不会删除写进原生目录的会话。此前独立的 Kaus 数据库、Project 和工作目录没有隔离原生历史，因此 Codex 桌面端能发现这些测试会话。

共用入口是 `kernel/drivers/discovery_scope.py`，原生存储约定在 `discovery_layouts.json`。ACP 目录探测、`probe_adapter.py` 与 `scripts/acp_smoke.py` 都接入它。它复制选中连接所需的配置和凭据文件到短期私有目录，重定向 HOME、XDG 及原生专有数据变量，不复制历史、数据库和记忆，不把可写符号链接指向原件。原生进程退出后才清理临时目录。缓存同时观察连接配置、凭据文件和程序变化。

特殊存储契约：

- Codex 的显式 `sqlite_home` 和 `log_dir` 也覆盖到临时目录；只改 `CODEX_HOME` 不足以覆盖用户自己配置的数据库路径。
- macOS Antigravity 需要原来的 HOME 身份访问原生 Keychain，因此保留该身份，将实际会话目录 `GEMINI_HOME` 重定向到临时目录。Kaus 不导出 Keychain 凭据，不发起额外授权。
- macOS Claude Code 将 `CLAUDE_CONFIG_DIR` 用作临时文件和历史目录，同时通过原生 `CLAUDE_SECURESTORAGE_CONFIG_DIR` 保留选中连接的 Keychain 身份；默认、显式配置目录和独立凭据目录分别测试。没有复制 Keychain token。当前安装的 CLI 2.1.228 包含这个原生入口；其他登录账号的真实生成仍需账号条件补验。

OpenClaw 目录探测改为 Gateway 的只读 `models.list`，不创建或修改会话。对这种外部服务进行真实生成测试必须使用独立 Gateway，改本机 HOME 不会隔离服务端历史；本地通用测试工具会拒绝把它当成本地隔离实例。

模型发现仍以原生协议选项为准。部分引擎在未登录时也返回公共目录，需遵循其原生连接状态：Claude 的原生认证通知、OpenCode/Kilo 的已配置 provider、DSH/DeepSeek ACP 和 Command Code 的原生连接配置。此逻辑位于驱动层，不在页面按品牌维护模型名单。新会话、已有会话、组长及模块复用共同的可选模型筛选。

正式客户端复核还暴露了认证通知晚于 `session/new` 返回的竞争：原生声明 `_meta.authStatus` 后，目录读取会有限等待该通知。未报告身份时不把创建会话当成已登录；明确退出登录的连接不能被随后返回的公共目录重新填满。未声明该扩展的引擎不额外等待。此契约来自安装的 [Claude ACP 适配器](https://github.com/agentclientprotocol/claude-agent-acp) 的异步认证实现，按协议能力声明接入，没有按品牌给前端加分支。

Hermes HTTP 不再在动态目录失败时扩张为静态厂商列表；失败时仅保留连接明确保存的当前模型，明确不可用的 provider 不会重新出现。有效的空目录保持为空。原生已连接目录中的选项不再因缺少 Kaus 自定义的验证字段而被降为“待确认”。

## 路径与交付范围

隔离规则是产品代码，不是写死这台 Mac 的用户名或个人路径。新版安装在其他设备时解析该用户自己的原生配置和系统临时目录。安装旧版本的用户需要更新版本才会获得这些修复。

正常数据位置本轮保持不变。当前只有分项路径覆盖，还没有完整的数据迁移界面。建议将 **Kaus 数据位置** 放在设置中，将 **Agent 原生数据路径** 放在对应连接的高级设置中；工作目录选择继续只决定任务在哪里工作。迁移需一起处理数据库、附件、模块数据及历史索引，并验证暂停写入、复制、校验、重启和回滚后再开放。此建议已进入交接待办，未将其标为交付。

主要真实环境为 macOS；任意自定义启动脚本若再次硬编码其他存储位置，需要按该脚本的存储契约补验。新增原生版本若改变存储规则，也需更新布局和回归，不能把 HOME 隔离当成任意程序的文件系统沙箱。

详细会话 ID、登录信息、测试输出和数据库核查保存在本机私有验收目录，不提交到公开仓库。没有清理用户已有聊天，也没有移动现有原生目录。
